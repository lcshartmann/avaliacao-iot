# Trabalho Avaliativo 04  - API REST - IoT
### Realizado por: Eduardo Freitas, Eliton Penke, Lucas Hartmann e Lucas Henrique.

Durante o projeto foram desenvolvidos um simulador de sensores IoT, uma API REST para receber e armazenar suas leituras e de uma aplicação web que consuma a API e apresenta os dados em um dashboard.

O projeto foi desenvolvido utilizado as seguintes tecnologias: Bun (TS runtime), TypeScript, React, TailWindCSS, Recharts e SQLite.

Dentro de cada diretório encontra-se um README com guia para setup e execução da API e do simulador.
